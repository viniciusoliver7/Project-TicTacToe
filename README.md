# Project-TicTacToe
About the TICTACTOE Project – 

This project is a TicTacToe game (jogo da velha) . It was create to practice C#.
The  Program is split in two archives,  Program.cs and TicTacToe.cs

Program.cs: this archive is the Main Code, basically it’s the archive that there the code that will be run first.


TicTacToe.cs : this archive contains the class  TicTacToe. The class is responsive for the operation game. It realize All functions of the game , for example, to process each move or to clean the game when it’s restarted.
