# Project-TicTacToe
About the TICTACTOE Project – 

This project is a TicTacToe game (jogo da velha) . It was create to practice C#.
The  Program is split in two archives,  Program.cs and TicTacToe.cs

Program.cs: this archive is the Main Code, basically it’s the archive where there is the code that will be run first.


TicTacToe.cs : this file contains the class  TicTacToe. The class is responsible for the game operation. It does All functions of the game , for example, to process each move or to clean the game when it’s restarted.
