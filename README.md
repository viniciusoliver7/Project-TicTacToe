# Project TicTacToe (C#)

A simple **Tic Tac Toe** game developed in **C#**, focused on practicing **programming logic**, **code structure**, and **class organization**.

This project is part of my study portfolio and professional growth as a **Data Engineer**, strengthening the logical foundations required to solve more complex problems such as data pipelines, automations, and data processing workflows.

---

## Features

* Tic Tac Toe game for **two players**
* **Console-based** interface
* Validation of invalid moves
* Win and draw detection
* Automatic player turn switching

---

## Technologies Used

* **C#**
* **.NET (Console Application)**
* Object-Oriented Programming (OOP)

## How to Run the Project

### Prerequisites

* .NET SDK installed (version 6.0 or higher)

### Step by step

```bash
# Clone the repository
git clone https://github.com/viniciusoliver7/Project-TicTacToe.git

# Navigate to the project folder
cd Project-TicTacToe

# Run the project
dotnet run
```
